## Calculadora de IMC en Python

Este programa pide datos del usuario como nombre, edad, peso y estatura para calcular el Índice de Masa Corporal (IMC).

Durante este proyecto practiqué:
- variables
- captura de datos
- validaciones
- operadores matemáticos
- condicionales
- ciclos while
