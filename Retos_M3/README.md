# Retos del Módulo 3

Esta carpeta contiene los retos semanales correspondientes al **Módulo 3: Funciones, Módulos y Paquetes** del bootcamp de Fundamentos de Python de UCAMP.

## Contenido

| Semana | Descripción | Archivo |
|---|---|---|
| **9** | Programa que muestra la letra anterior y la siguiente dentro del alfabeto mediante una función. | [`Semana9.py`](Semana9.py) |
| **10** | Programa que crea dos listas y elimina de la primera los elementos que también aparecen en la segunda. | [`Semana10.py`](Semana10.py) |
| **11** | Variante que permite crear varias listas y elimina de cada una los elementos que aparecen en listas posteriores. Las funciones se encuentran en un módulo separado. | [`Semana11/`](Semana11/) |
| **12** | Programa que registra las ventas de cada año dentro de un rango y genera una gráfica de líneas. | [`Semana12.py`](Semana12.py) |

## Dependencia para gráficas

La semana 12 utiliza Matplotlib. Desde la raíz del repositorio se puede instalar con:

```bash
pip install -r requirements.txt
```

## Ejecutar la semana 12

Desde la raíz del repositorio:

```bash
python Retos_M3/Semana12.py
```

En algunos sistemas puede ser necesario utilizar `python3` y `pip3`.
