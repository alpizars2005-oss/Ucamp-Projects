## Qué se puede afirmar

**Verificado:** existe un prototipo académico local para pedidos, recetas e inventario con datos de demostración.  
**Propuesta:** uso comercial de Instagram y WhatsApp Business, integración manual de consultas y pedidos.  
**Pendiente:** investigar usuarios y preferencias, medir demanda, observar operación real y validar viabilidad comercial.
